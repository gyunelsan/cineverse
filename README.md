🎬 CineVerse - Movie Streaming Website
CineVerse is a dynamic movie streaming website that allows users to explore the latest films, watch trailers, and get detailed information about each movie.

🚀 Features
📌 Dynamic Movie Listings – Stay updated with the latest movies fetched from an API.

🎞️ Trailers & Movie Details – View trailers and detailed information, including ratings and release dates.

📱 Responsive Design – Fully optimized for mobile, tablet, and desktop users.

🎨 Modern UI – Built with React and Bootstrap for a sleek, user-friendly experience.


🛠️ Technologies Used
HTML, CSS, JavaScript – Core web technologies for structure and interactivity.
React – For building a dynamic and efficient user interface.
Bootstrap – For styling and responsive design.
TMDb API – To fetch movie data and trailers dynamically.
